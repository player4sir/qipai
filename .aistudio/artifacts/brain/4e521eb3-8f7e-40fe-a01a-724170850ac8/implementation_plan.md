# 斗地主（Dou Dizhu）商业化赛事级重构方案

针对当前斗地主模块存在的**特效贴图错位与未切片乱象**、**WebAudio/TTS 合成音频残留**、**博弈与提示算法拆牌粗糙**以及**牌桌 HUD 视觉冗余**四大核心问题，制定以下生产级重构方案。

---

## 一、 音频系统商业化清理与真实音源全量映射 (`src/shared/audio/SoundEngine.ts` & `GameStateManager.ts`)

### 1. 彻底清除所有合成音与 TTS 代码
- **零合成音承诺**：从 `src/shared/audio/SoundEngine.ts` 中彻底移除所有 `ctx.createOscillator()`、程序化噪声缓冲区（`createBuffer` 白噪/粉噪生成）、合成器 BGM 音序器（`startSynthesizedBgm`）以及 `window.speechSynthesis`（`speak()`）代码。
- **真实音频池架构**：统一通过 `AudioBuffer` 预加载缓存池 + `HTMLAudioElement` 降级通道驱动，确保所有游戏音效 100% 来源于 `/public/assets/audio/` 下的真实商业录音文件。

## 二、 特效系统与序列帧切片重构 (`src/games/ddz/scenes/DdzVfxEngine.ts` & `GameScene.ts`)

### 1. 彻底剔除错位与黑底废图
- **移除 `fx_light_burst.png`**：经核查该文件实为印有 `"HAPPY POKER"` 的蓝白信封底图，此前被误当成放射光效在顺子、炸弹、王炸和春天中旋转放大，导致画面出现一张混乱信封图，现彻底从特效管线剔除。
- **移除黑底未裁切的 `csr_huoxing.png` 与错位 `csr_zha.png`**：不再直接将整张未抠图的黑底火星图或竖向光柱图当作炸弹本体渲染。

### 2. 构建序列帧切片器与商业级 `DdzVfxEngine`
新建独立特效引擎 `src/games/ddz/scenes/DdzVfxEngine.ts`，实现标准矩形序列帧切片工具 `sliceSpritesheetFrames(texture, cols, rows)`（基于 `new Texture({ source: baseTexture.source, frame: new Rectangle(...) })`），并结合高品质 GPU 矢量/Canvas 烘焙序列帧与真实美术字贴图（`title_wuzha.png`、`sy_chuntian.png`、`title_chuntian_js.png`）：
- **顺子 / 连对（流光弧线 + 序列帧星芒 + 金色书法字牌）**：
  - 绘制刀光级贝塞尔流光扫过出牌区，伴随切片星芒粒子沿牌面滑行，中央弹出带金属斜切高光的“顺子 / 连对”徽章，干净利落。
- **飞机 / 飞机带翅膀（真实双翼机编队掠过 + 地面投影 + 涡流尾迹）**：
  - 配合 `Special_plane.wav`，先投射斜向机身地面阴影，随后金属质感双翼机身携螺旋桨高速旋转残影、双翼流光尾迹与气压波纹横穿牌桌，移除突兀的信封背景图。
- **炸弹（抛物线重型炸弹 + 引信火花切片动画 + 碎石冲击波）**：
  - 从出牌席位抛出带燃烧引信序列帧的立体金属炸弹，旋转落入牌桌中心；引爆瞬间触发双层空气折射扩散环、高光裂纹与无黑底的纯 Alpha 火星碎片飞溅，伴随克制的屏幕震动（`Special_Bomb_New.wav`）。
- **王炸 / 火箭（双王锁定 + 升空尾焰 + `title_wuzha.png` 核爆全屏震荡）**：
  - 大小王卡牌幻影在牌桌中心交汇锁定，垂直金色光柱冲天而起，随后顶部重型火箭俯冲引爆，弹出真实美术字贴图 `/assets/ui/title_wuzha.png`（“王炸”）与多层金色冲击波（`Special_Long_Bomb.wav`）。
- **春天 / 反春（`sy_chuntian.png` + 迎春花瓣飘落与金光卷轴）**：
  - 调用真实美术贴图 `/assets/ui/sy_chuntian.png` 与 `/assets/ui/title_chuntian_js.png`，配合丝滑的金色光束与桃花花瓣物理飘落动画（`Special_Chuntian.wav`）。
- **余牌警报灯（1/2张红蓝警灯脉冲）**：
  - 当任意玩家手牌剩余 1 或 2 张时，席位旁激活真实感红光旋转警示灯环与剩余张数高亮角标。

## 三、 斗地主竞技博弈算法与防拆炸智能提示 (`DdzBotEngine.ts` & `DdzRules.ts` & `HandManager.ts`)

### 1. 最小手数 DFS 拆牌估值引擎 (`evaluateHandPartition`)
- **全局最优拆牌搜索**：在 `DdzBotEngine.ts` 与 `DdzRules.ts` 中升级深度优先（DFS + 剪枝）最小手数拆牌器，遍历顺子、连对、飞机、三张的交叉组合，寻找使**净手数（`netTurns = 总拆分手数 - 炸弹/火箭数 - 大牌控制力修正`）**最小的唯一最优拆牌树。
- **带牌（Kicker/Wing）损耗融合计算**：计算手数时自动将三张/飞机与最弱单张或对子配对消减手数，避免把成型的三带一拆散计算。

### 2. 防拆炸 4 级智能提示优先级队列 (`getValidMoves` / `getSortedHints`)
重构玩家点击“提示”按钮及滑动选牌时的候选牌生成逻辑，严格按以下 4 级优先级排序轮播：
1. **Tier 1（零破坏纯牌型）**：直接匹配当前手牌拆牌树中的独立单张、独立对子、独立三带、独立顺子，**绝对不拆分**任何连对、顺子、三张、炸弹或王炸。
2. **Tier 2（柔性拆顺/拆三带）**：当无纯牌型可管时，允许从长顺子末端剥离或拆散普通三张/连对，但**严禁触碰任何四张炸弹与双王**。
3. **Tier 3（炸弹接管）**：当普通牌型无法压制桌面牌时，按点数从小到大依次提示普通四张炸弹。
4. **Tier 4（王炸兜底 & 拆炸保命）**：最后提示王炸（火箭）；仅在对手已报单/报双且无其他解牌的极端残局下，才允许将炸弹拆为三带或单牌提示。

### 3. 农民上下家协同博弈（顶牌者 Gatekeeper vs. 送牌者 Feeder）
- **地主上家（顶牌手 Gatekeeper）**：
  - 领出时若地主余牌较多，优先出中大单张（如 Q、K、A）或紧凑对子顶住地主小牌过桥；压牌时积极拦截地主顺子与三带，绝不轻易放地主小牌过河。
- **地主下家（顺牌/送牌手 Feeder）**：
  - 当上一手牌为队友（农民同伴）打出且点数已较大（如 ≥ J 的单牌或对子），或者队友已进入报双/报单残局时，严格执行**不压队友牌（Pass）**；
  - 当自身领出且队友已报单（剩 1 张）或报双（剩 2 张）时，主动打出手中**最小单张或最小对子**喂牌助队友走完，甚至在自身有炸弹可护航时先炸后送最小牌。

## 四、 商业级克制牌桌场景与 HUD 重构 (`src/games/ddz/DdzTableView.tsx` & `GameScene.ts`)

### 1. 赛事级紧凑顶栏（底牌 + 实时倍率明细 + 折叠记牌器）
- **一体化克制顶栏**：采用磨砂深灰黑（`rgba(15, 20, 28, 0.82)` + `backdrop-filter: blur(12px)` + `1px solid rgba(255,255,255,0.08)`）整合顶部信息：
  - **左侧**：紧凑返回按钮、房间场次/底分徽章、局数进度。
  - **中央**：3 张底牌微缩展示槽（未叫完地主前显示精致牌背，确认地主后翻开并标注底牌特殊倍率角标，如`同花×2`、`顺子×2`、`大王×2`、`双王×4`）+ 当前总倍率数字（点击可展开克制的倍率构成浮层：初始、抢地主、底牌、加倍、炸弹、春天明细）。
  - **右侧**：可一键展开/收起的**紧凑型剩余记牌器（大王~3 实时剩余张数统计条）**、托管切换与静音开关。

### 2. 精简席位 HUD 与清晰出牌区
- **左右对手席位卡片**：摒弃臃肿拉伸的边框，采用定宽紧凑胶囊/微卡片设计，清晰展示头像、地主/农民金色徽章、昵称、豆子/积分、加倍状态标签（`加倍×2` / `超级加倍×4`）以及醒目的**剩余手牌数字牌背计数器**（剩 1~2 张时触发红光报警呼吸灯）。
- **三方独立出牌展示区**：精准校准左家、右家、本家三个出牌锚点坐标与牌面缩放比例（`0.68x`），确保打出长顺子或飞机带翅膀时自动居中折行或紧凑叠放，绝不与头像 HUD 或手牌区重叠。
- **底部人体工学操作栏与手牌区**：
  - 叫分/抢地主、加倍/超级加倍、不出/提示/出牌按钮全部采用**定宽紧凑圆角规范**（严禁随容器拉伸变形），主操作按钮（出牌/抢地主/超级加倍）采用琥珀金质感渐变，次操作（不出/不抢/不加倍）采用克制深灰玻璃态，辅助操作（提示）采用冷翠绿/蓝灰边框态。
